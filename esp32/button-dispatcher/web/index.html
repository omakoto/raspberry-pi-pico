Button dispatcher

Devices

A device is a remote or a button. All the physical buttons of one remote belong to the same device; each physical button gets its own binding (Bindings tab).

Bindings

Satellites

A satellite is another board running this firmware, set to the satellite role and placed near buttons that are too far from this one. It forwards the presses it hears over Wi-Fi, and this board handles them as if it had heard them itself.

Status

Forwarding to the dispatcher

This board is a satellite: it forwards the button presses it hears to its dispatcher, which runs the bindings. To make it a dispatcher again, change its role in Settings.

Pairing

The part after "@" is the dispatcher's address; you can change it to an IP address if its name does not resolve.
